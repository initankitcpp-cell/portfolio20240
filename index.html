THL (Training Hub Labs) – Business Website, Lead Automation & Owner Portal

Private client project

Overview

Built a conversion-focused website for a GIS and drone-survey training company from a client's hand-drawn wireframe, plus an automated lead-capture pipeline and a planned owner-only portal for finance and HR.

Problem

  • No professional web presence matching the company's scale (9 survey services, 10 training courses, research work).
  • Enquiries came through calls and WhatsApp with no tracking.
  • Owner ran three businesses with no unified view of revenue, expenses, pending payments or staff attendance.

What I Built

  • Responsive website: homepage (header, stats band, Projects / Trainings / Core Clients panels, gallery, contact form), services and training pages, and a gallery route with approval-gated photos.
  • Mobile-first UX: simplified mobile header and WhatsApp click-to-chat CTAs (wa.me deep link configured via env var).
  • Lead pipeline: form → Google Apps Script web app → validated, sanitized (formula-injection-safe) row in Google Sheets → instant email alert to the client.
  • Automation (n8n): webhook → JavaScript node to normalise the payload → append to a Sheets copy tab + Gmail notification + IF check → HTML thank-you auto-reply to the visitor.
  • Planned owner-only portal (Supabase): Finance module (3 businesses, per-business profit, receivables tracker with party contacts) and HRMS (employees, attendance, payroll, advances) with Row Level Security.

Key Engineering Decisions

  • Dual lead paths: Apps Script as the always-on primary (zero cost, no vendor lock-in) and n8n as secondary automation, so a workflow failure never loses a lead.
  • Sanitised all sheet inputs against formula injection.
  • Gated unverified accreditations and client logos behind a verified flag so nothing unproven is published.
  • Env-var driven config (lead endpoint, WhatsApp number) for easy handover.

Challenges & Fixes

  • Private-repo auth and PATH issues on Windows — resolved with gh device login and fixing the Bun PATH.
  • n8n payload arrived as a raw JSON string — fixed with a Code node to parse and flatten it.
  • Debugged email deliverability (Gmail “SENT” vs. inbox/spam).

Outcome

  • Working lead capture with email alerts and visitor auto-reply.
